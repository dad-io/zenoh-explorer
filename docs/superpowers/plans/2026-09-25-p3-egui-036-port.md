# P3: egui 0.36 Port and UI Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Zenoh Explorer from egui/eframe 0.29.1 to 0.36.2 and from rfd 0.14 to 0.17.2. Then use the port to gain UI infrastructure that lasts:
- `egui_kittest` UI tests.
- A virtualized topic tree.
- Persisted settings.
- Accessible labels.
- File dialogs and file I/O that do not block the UI thread.
- A clean shutdown.
- A window that works at 720×480.

**Architecture:**
- **Wave 0 runs one task at a time.**
  - T1 is a small mechanical compile port. It also makes every `Cargo.toml` change that later tasks need.
  - T2 adds the shared helper `src/dialogs.rs` for file dialogs and chunked I/O.
  - T3 adds scaffolding: module declarations, pre-declared app fields, call sites, the kittest harness, and one empty test file per lane.
- **After Wave 0, four lanes run in parallel on disjoint files:**
  - **Lane A** (`src/app/{mod,layout,theme}.rs`, `main.rs`, `settings.rs`): the app shell. This covers `logic`/`ui`, theme, persistence, `on_exit`, window size and the renderer decision.
  - **Lane B** (`topic_tree.rs`, `tree_rows.rs`): tree virtualization, tree accessibility and keyboard focus in the tree.
  - **Lane C** (`publish.rs`, `query.rs`, `messages.rs`, `help.rs`, `file_jobs.rs`, `transfer.rs`): async dialogs, import state, form accessibility and keyboard order. `help.rs` gets only the scroll-source line on P1 T26's Help scroll area.
  - **Lane D** (`src/ui/tests/views.rs`, `snapshots.rs`, CI): smoke and snapshot tests.
- **T17** integrates and verifies everything.

**Tech Stack:**
- Rust 2021, MSRV **1.95**.
- egui / eframe **0.36** (features `glow`, `default_fonts`, `wayland`, `x11`, `accesskit`, `persistence`).
- rfd **0.17** (`AsyncFileDialog`), pollster 0.4, serde (derive).
- egui_kittest **0.36** (dev: `eframe`, `wgpu`, `snapshot`).
- zenoh 1.x and tokio are unchanged.

- **Expander:** do not change the visuals or timing of `plus_minus_icon` (`topic_tree.rs:71-96`). Keep `style.animation_time = 0.001`, because it drives the expander's `openness`.
- **Renderer:** keep the glow renderer unless T8's measurements meet its switch rule.
- **Lane ownership:** a task modifies or creates only the files in its **Owns** list. Tests for a lane live in that lane's own file under `src/ui/tests/`.
- **Where UI tests live:** kittest tests live inside the binary crate (`src/ui/tests/`), because an integration test under `tests/` cannot reach the internals of a bin-only crate. Snapshot tests that need a GPU are `#[ignore = "needs a wgpu adapter"]` and run in the `ui-snapshots` CI job.

## Review Focus

- **Window minimized while samples arrive:** the pipeline must keep draining, with no growth in the "pipeline" drop count. In 0.36, `App::ui` does not run while the window is hidden. This is pinned by T4 `tick_drains_events_without_ui` and checked manually in T17.
- **Cancelling a file dialog:** no alert, no state change and no stuck progress bar. This is pinned by T3 `cancelled_jobs_leave_no_trace`.
- **Corrupt or old-format settings on disk:** the app starts with defaults instead of panicking. This is pinned by T5 `missing_and_corrupt_values_load_as_none`.
- **A filter that matches nothing, while the tree is virtualized:** the "No topics match the filter" message still shows. This is pinned by T10 `unmatched_filter_shows_message`.
- **A narrow window (720 px) with every header indicator active:** no status label overlaps the title or leaves the window. This is pinned by T7 `header_fits_at_720`.
- **P1's truthful-state additions survive the port** (count units, paused marker, branch summary, status lines; see Prerequisites). T10's `show_tree_row` rewrite moves the row body unchanged, so every row element P1 T24 added stays (T10 Step 4 lists them and greps for them). Checked by hand in T17 Step 3.
- **Filtering twice with different text:** a branch collapsed during the first filter is open again in the second. Pinned by T9 `filtered_open_state_is_per_query`. (UI review F-T13-2)
- **Tab past a disabled key:** forward Tab from the Subscribe key reaches the tree, from before Save File reaches Pause, and from Encoding reaches the Queryable's Key Pattern field past a disabled Publish. Pinned by T11 `tab_passes_disabled_subscribe` and `tab_passes_disabled_save_file`, and T14 `tab_passes_disabled_publish`. (F-T7-12)
- **Tab down a tree longer than the panel:** each focused row scrolls into view, so Tab keeps walking the virtualized rows instead of leaving the tree at the fold. Pinned by T11 `focused_row_scrolls_into_view`. (F-T7-14)
- **An import that fails, or a file over the import cap:** the draft and the encoding are unchanged and the reason is an error alert, never payload text. Pinned by T2 `import_refuses_file_over_cap` and T12 `apply_import_error_keeps_draft`. (F-T8-8, F-T15-5)
- **Encoding after an import:** Import sets the encoding from the file extension and shows "Encoding set from file", and Clear or publishing the import puts back what the user had, unless the user edited the encoding meanwhile. T12 `import_infers_and_restores_encoding` pins the inference, the note, the ✖ Clear path and the kept typed encoding (through `end_import`). It does not drive a publish: that path is pinned only by T12's `grep -c 'self.end_import()'` = 2 and checked by hand in T12 Step 5 and T17 Step 3 item 10. (F-T15-4)
- **Typing a limit:** selecting Memory Limit's "100" and typing `5` leaves 100 in force until Enter, and `50` then applies as 50, not 10. Pinned by T14 `limits_are_drag_values`. (F-T4-9)
- **The dedup switch at 720 px:** "List each sample once" is on screen. Pinned by T14 `messages_toolbar_fits_at_720`, which checks position only. Its hover states P1 T16's rule, built from `DEDUP_WINDOW` so the number cannot drift from the code; the hover wording is checked by hand in T14 Step 5 and T17 Step 3 item 10. (F-T4-11)

```rust
use std::io::{Read, Write};
use std::path::{Path, PathBuf};
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::mpsc::{self, Receiver, TryRecvError};
use std::sync::Arc;

/// Bytes moved per read/write call; progress advances in these steps.
pub const IO_CHUNK: usize = 8 * 1024 * 1024;

/// Final result of a file job.
#[derive(Debug)]
pub enum FileJobOutcome {
    /// A file was picked and fully read.
    Imported { filename: String, bytes: Vec<u8> },
    /// The file was written to `path`.
    Exported { path: PathBuf },
    /// The user closed the dialog without choosing a file.
    Cancelled,
    /// Reading, reassembling or writing failed; the text is shown to the user.
    Failed(String),
}

/// Bytes done out of bytes total. `total == 0` means "not known yet".
#[derive(Debug, Default)]
pub struct Progress {
    pub done: AtomicU64,
    pub total: AtomicU64,
}

impl Progress {
    /// Completed fraction in 0..=1, or `None` while the total is unknown.
    pub fn fraction(&self) -> Option<f32> {
        let total = self.total.load(Ordering::Relaxed);
        (total > 0).then(|| {
            (self.done.load(Ordering::Relaxed) as f64 / total as f64).min(1.0) as f32
        })
    }
}

/// A running import or export. Poll it once per frame.
pub struct FileJob {
    /// Short verb for the status line, e.g. "Importing" or "Saving".
    pub label: &'static str,
    pub progress: Arc<Progress>,
    rx: Receiver<FileJobOutcome>,
}

impl FileJob {
    /// Run `work` on a new thread; `notify` is called once the outcome is sent.
    pub(crate) fn spawn(
        label: &'static str,
        work: impl FnOnce(&Progress) -> FileJobOutcome + Send + 'static,
        notify: impl Fn() + Send + 'static,
    ) -> Self {
        let progress = Arc::new(Progress::default());
        let (tx, rx) = mpsc::channel();
        let p = progress.clone();
        std::thread::Builder::new()
            .name(format!("file-job-{label}"))
            .spawn(move || {
                let _ = tx.send(work(&p));
                notify();
            })
            .expect("spawn file job thread");
        Self { label, progress, rx }
    }

    /// The outcome once the job has finished, else `None`.
    pub fn poll(&self) -> Option<FileJobOutcome> {
        match self.rx.try_recv() {
            Ok(outcome) => Some(outcome),
            Err(TryRecvError::Empty) => None,
            Err(TryRecvError::Disconnected) => Some(FileJobOutcome::Failed(
                "file job ended without a result".into(),
            )),
        }
    }
}

/// Read a whole file in `IO_CHUNK` pieces, updating `progress`.
pub fn read_with_progress(path: &Path, progress: &Progress) -> std::io::Result<Vec<u8>> {
    let mut file = std::fs::File::open(path)?;
    let len = file.metadata()?.len();
    progress.total.store(len, Ordering::Relaxed);
    let mut out = Vec::with_capacity(len as usize);
    let mut buf = vec![0u8; IO_CHUNK.min(len.max(1) as usize)];
    loop {
        let n = file.read(&mut buf)?;
        if n == 0 {
            break;
        }
        out.extend_from_slice(&buf[..n]);
        progress.done.fetch_add(n as u64, Ordering::Relaxed);
    }
    Ok(out)
}

/// Write `bytes` in `IO_CHUNK` pieces, updating `progress`.
pub fn write_with_progress(path: &Path, bytes: &[u8], progress: &Progress) -> std::io::Result<()> {
    progress.total.store(bytes.len() as u64, Ordering::Relaxed);
    let mut file = std::fs::File::create(path)?;
    for chunk in bytes.chunks(IO_CHUNK) {
        file.write_all(chunk)?;
        progress.done.fetch_add(chunk.len() as u64, Ordering::Relaxed);
    }
    file.flush()
}

/// Save-dialog filters: the suggested name's own extension first (so no
/// platform appends `.bin`), then "All files". Same order the blocking
/// `transfer::export_payload_to_file` used.
pub fn export_filters(suggested_name: &str) -> Vec<(String, Vec<String>)> {
    let mut filters = Vec::new();
    if let Some(ext) = Path::new(suggested_name).extension().and_then(|e| e.to_str()) {
        filters.push((format!("{} files", ext.to_uppercase()), vec![ext.to_string()]));
    }
    filters.push(("All files".to_string(), vec!["*".to_string()]));
    filters
}

/// Open the native "open file" dialog and read the chosen file off-thread,
/// refusing a file larger than `max_bytes` before reading it.
#[allow(dead_code)] // called from the Publish tab once T12 lands
pub fn spawn_import(ctx: egui::Context, max_bytes: u64) -> FileJob {
    let dialog = rfd::AsyncFileDialog::new().pick_file();
    FileJob::spawn(
        "Importing",
        move |progress| match pollster::block_on(dialog) {
            None => FileJobOutcome::Cancelled,
            Some(handle) => {
                let path = handle.path().to_path_buf();
                if let Some(e) = import_size_error(&path, max_bytes) {
                    return FileJobOutcome::Failed(e);
                }
                match read_with_progress(&path, progress) {
                    Ok(bytes) => FileJobOutcome::Imported { filename: handle.file_name(), bytes },
                    Err(e) => FileJobOutcome::Failed(format!("{}: {e}", path.display())),
                }
            }
        },
        move || ctx.request_repaint(),
    )
}

/// Open the native "save file" dialog; after the user picks a path, call
/// `load` (e.g. chunk reassembly) and write the bytes, all off-thread.
#[allow(dead_code)] // called from Save once T13 lands
pub fn spawn_export(
    ctx: egui::Context,
    suggested_name: &str,
    load: impl FnOnce() -> Result<Vec<u8>, String> + Send + 'static,
) -> FileJob {
    let mut dialog = rfd::AsyncFileDialog::new().set_file_name(suggested_name);
    for (name, exts) in export_filters(suggested_name) {
        dialog = dialog.add_filter(name, &exts);
    }
    let dialog = dialog.save_file();
    FileJob::spawn(
        "Saving",
        move |progress| {
            let Some(handle) = pollster::block_on(dialog) else {
                return FileJobOutcome::Cancelled;
            };
            let path = handle.path().to_path_buf();
            let bytes = match load() {
                Ok(b) => b,
                Err(e) => return FileJobOutcome::Failed(e),
            };
            match write_with_progress(&path, &bytes, progress) {
                Ok(()) => FileJobOutcome::Exported { path },
                Err(e) => FileJobOutcome::Failed(format!("Failed to write {}: {e}", path.display())),
            }
        },
        move || ctx.request_repaint(),
    )
}
```

```rust
//! File jobs (import/export) as seen by the UI: start Save, poll finished
//! jobs every frame (from `App::logic`, so they finish while hidden), and
//! show a progress line for each running job.

use std::time::Duration;

use crate::app::{UiAlert, ZenohExplorer};
use crate::dialogs::FileJobOutcome;
use crate::transfer;
use crate::ui::publish::PublishUI;

pub trait FileJobsUI {
    fn save_topic_to_file(&mut self, topic: &str);
    fn poll_file_jobs(&mut self, ctx: &egui::Context);
    fn show_file_jobs(&mut self, ui: &mut egui::Ui);
}

impl FileJobsUI for ZenohExplorer {
    /// Run the full save flow for a topic: fetch/reassemble, native dialog,
    /// write — surfacing any failure in the global alert banner.
    fn save_topic_to_file(&mut self, topic: &str) {
        let result = self
            .payload_store
            .read()
            .map_err(|_| "Payload store lock poisoned".to_string())
            .and_then(|store| transfer::get_payload_for_export(&store, topic));
        match result {
            Ok(payload) => {
                let suggested = transfer::suggested_export_filename(topic, payload.filename.as_deref());
                match transfer::export_payload_to_file(&suggested, &payload.bytes) {
                    Ok(Some(path)) => {
                        self.ui_alert = Some(UiAlert::Success(format!("Saved to {}", path.display())))
                    }
                    Ok(None) => {} // user cancelled
                    Err(e) => self.ui_alert = Some(UiAlert::Error(format!("Save failed: {}", e))),
                }
            }
            Err(e) => self.ui_alert = Some(UiAlert::Error(format!("Save failed: {}", e))),
        }
    }

    fn poll_file_jobs(&mut self, ctx: &egui::Context) {
        if let Some(outcome) = self.import_job.as_ref().and_then(|j| j.poll()) {
            self.import_job = None;
            match outcome {
                FileJobOutcome::Imported { filename, bytes } => self.apply_import(Ok((filename, bytes))),
                FileJobOutcome::Failed(e) => self.apply_import(Err(e)),
                FileJobOutcome::Cancelled | FileJobOutcome::Exported { .. } => {}
            }
        }
        if let Some(outcome) = self.export_job.as_ref().and_then(|j| j.poll()) {
            self.export_job = None;
            match outcome {
                FileJobOutcome::Exported { path } => {
                    self.ui_alert = Some(UiAlert::Success(format!("Saved to {}", path.display())));
                }
                FileJobOutcome::Failed(e) => self.ui_alert = Some(UiAlert::Error(format!("Save failed: {e}"))),
                FileJobOutcome::Cancelled | FileJobOutcome::Imported { .. } => {}
            }
        }
        if self.import_job.is_some() || self.export_job.is_some() {
            // Progress atomics change without events; keep the bar moving.
            ctx.request_repaint_after(Duration::from_millis(100));
        }
    }

    fn show_file_jobs(&mut self, ui: &mut egui::Ui) {
        for job in [&self.import_job, &self.export_job].into_iter().flatten() {
            ui.horizontal(|ui| {
                ui.label(format!("{}…", job.label));
                let bar = egui::ProgressBar::new(job.progress.fraction().unwrap_or(0.0)).desired_width(160.0);
                ui.add(if job.progress.fraction().is_some() { bar.show_percentage() } else { bar });
            });
        }
    }
}
```

```rust
pub const SETTINGS_KEY: &str = "zenoh_explorer_settings_v1";

/// What survives a restart. Missing fields fall back to `Default`.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(default)]
pub struct Settings {
    pub connection_mode: String,
    pub connect_transport: String,
    pub connect_address: String,
    pub connect_port: String,
    pub listen_port: String,
    pub dark_mode: bool,
    /// Key expressions to re-subscribe after the next successful connect.
    pub subscriptions: Vec<String>,
    pub tree_filter: String,
}

impl Default for Settings {
    /// Matches the defaults in `ZenohExplorer::new`.
    fn default() -> Self {
        Self {
            connection_mode: "peer".into(),
            connect_transport: "tcp".into(),
            connect_address: String::new(),
            connect_port: "7447".into(),
            listen_port: "7447".into(),
            dark_mode: true,
            subscriptions: Vec::new(),
            tree_filter: String::new(),
        }
    }
}

impl Settings {
    /// Read settings; `None` when absent or unreadable (e.g. older format).
    pub fn load(storage: &dyn eframe::Storage) -> Option<Self> {
        eframe::get_value(storage, SETTINGS_KEY)
    }

    /// Write settings; eframe flushes storage to disk.
    pub fn store(&self, storage: &mut dyn eframe::Storage) {
        eframe::set_value(storage, SETTINGS_KEY, self);
    }
}
```

```rust
    pub(crate) fn shutdown(&mut self, deadline: std::time::Duration) -> bool {
```

```rust
/// Minimum interval between rebuilds caused only by new data.
pub const ROWS_REBUILD_INTERVAL: Duration = Duration::from_millis(250);

/// Rebuild at once when the filter or expansion changed; rebuild on new
/// data at most every `ROWS_REBUILD_INTERVAL`.
pub fn rows_cache_is_stale(cache: Option<&TreeRowsCache>, key: &TreeRowsKey, now: Instant) -> bool {
    match cache {
        None => true,
        Some(c) if c.key.filter != key.filter || c.key.expand_generation != key.expand_generation => true,
        Some(c) => {
            c.key.tree_version != key.tree_version
                && now.duration_since(c.built_at) >= ROWS_REBUILD_INTERVAL
        }
    }
}

/// The filter text as the tree keys it: trimmed and lower-cased.
pub fn filter_text_key(raw: &str) -> String {
    raw.trim().to_lowercase()
}

/// egui id under which a branch's open/closed state is stored. Filtering
/// uses a separate namespace per filter text, so the user's normal expansion
/// is untouched and restored when the filter is cleared, and a collapse made
/// under one filter does not carry over to the next filter session.
pub fn row_state_id(full_path: &str, filter: &str) -> egui::Id {
    if filter.is_empty() {
        egui::Id::new(("treenode", full_path))
    } else {
        egui::Id::new(("treenode_filtered", filter, full_path))
    }
}

/// Depth-first, key-ordered list of the rows that are visible: in the
/// filter's `visible` set (when filtering) and under open branches only.
pub fn flatten_rows(
    root: &ZenohNode,
    visible: Option<&HashSet<String>>,
    is_open: &dyn Fn(&str) -> bool,
) -> Vec<TreeRow> {
    fn walk(
        node: &ZenohNode,
        path: String,
        depth: usize,
        visible: Option<&HashSet<String>>,
        is_open: &dyn Fn(&str) -> bool,
        out: &mut Vec<TreeRow>,
    ) {
        if visible.is_some_and(|v| !v.contains(&path)) {
            return;
        }
        let is_branch = !node.children.is_empty();
        let open = is_branch && is_open(&path);
        out.push(TreeRow { full_path: path.clone(), depth, is_branch });
        if open {
            for (key, child) in &node.children {
                walk(child, format!("{path}/{key}"), depth + 1, visible, is_open, out);
            }
        }
    }
    let mut out = Vec::new();
    for (key, child) in &root.children {
        walk(child, key.clone(), 0, visible, is_open, &mut out);
    }
    out
}
```

```rust
/// Preview sizes for an imported file: collapsed and expanded.
const PREVIEW_COLLAPSED: usize = 256;
const PREVIEW_EXPANDED: usize = 4 * 1024;

/// Encoding Import sets for a file, from its extension (UI review F-T15-4).
/// Every value is one of zenoh's predefined encodings.
fn encoding_for_filename(name: &str) -> &'static str {
    let ext = std::path::Path::new(name)
        .extension()
        .and_then(|e| e.to_str())
        .map(str::to_ascii_lowercase);
    match ext.as_deref() {
        Some("json") => "application/json",
        Some("txt" | "log") => "text/plain",
        Some("csv") => "text/csv",
        Some("md") => "text/markdown",
        Some("html" | "htm") => "text/html",
        Some("xml") => "application/xml",
        Some("yaml" | "yml") => "application/yaml",
        Some("png") => "image/png",
        Some("jpg" | "jpeg") => "image/jpeg",
        Some("gif") => "image/gif",
        _ => "application/octet-stream",
    }
}

/// At most `limit` bytes of an import: text when the whole file is UTF-8
/// (`is_utf8`, decided once in `apply_import`), else hex. Only the shown
/// prefix is decoded, so Expand and Collapse never rescan the file (F-T15-5).
fn import_preview(bytes: &[u8], is_utf8: bool, limit: usize) -> String {
    let total_len = bytes.len();
    let preview_len = total_len.min(limit);
    if is_utf8 {
        // A cut inside a multi-byte char leaves an incomplete tail; drop it.
        let head = bytes[..preview_len].utf8_chunks().next().map_or("", |c| c.valid());
        if total_len > head.len() {
            format!("{}... [+{} bytes]", head, total_len - head.len())
        } else {
            head.to_string()
        }
    } else {
        let hex: String = bytes[..preview_len].iter().map(|b| format!("{:02x} ", b)).collect();
        if total_len > preview_len {
            format!("{}... [+{} bytes, {} total]", hex.trim(), total_len - preview_len, total_len)
        } else {
            hex
        }
    }
}

/// The size shown next to an imported file name, e.g. "(1.50 GB · binary)".
fn import_size_label(len: usize, is_utf8: bool) -> String {
    let kind = if is_utf8 { "text" } else { "binary" };
    format!("({} · {kind})", crate::transfer::format_size(len))
}
```

```rust
/// Transmitted filename for a topic's stored payload, without copying bytes:
/// the direct entry's, else the lowest-index chunk of the newest group.
pub fn stored_filename(store: &PayloadStoreMap, topic: &str) -> Option<String> {
    if let Some(e) = store.get(topic) {
        return e.filename.clone();
    }
    let p = chunk_progress(store, topic)?;
    store
        .iter()
        .filter_map(|(k, e)| parse_chunk_key(k).map(|(t, m)| (t, m, e)))
        .filter(|(t, m, _)| *t == topic && m.total_size == p.total_size && m.total_chunks == p.total_chunks)
        .min_by_key(|(_, m, _)| m.index)
        .and_then(|(_, _, e)| e.filename.clone())
}
```
